面試掣記欄

  • 只談理想、不談職責 — 少提個案、導師管理、假期託管、行政。
  • 只談熱誠、不談例子 — 沒有具體課託／學校場景與結果。
  • 危機題忽略程序 — 只說陪伴，沒提安全、督導、紀錄、通報。
  • 答應兒童「絕對保密」 — 疑似虐兒時保密有例外。
  • 迴避輪班 — 不正面回應週末／假期工作安排。
  • 例子沒有結果 — 有情境無行動，或有行動無成效。
  • STAR（行為題）：情境 Situation → 任務 Task → 行動 Action → 結果 Result。
  • 危機三步：即時安全 → 專業介入／分工 → 通報跟進與預防。
  • 保護兒童：不承諾絕對保密 → 評估紀錄 → 督導／機構程序。
  • 導師管理：核實事實 → 澄清期望 → 支援提升 → 問責期限。
  • 90 日計劃：熟悉流程 → 建立關係 → 優化營運與檢討。
  • 計劃目標：在校課後託管與學習支援；支援家長（尤其單親／雙職）外出工作。
  • 主任職責：家長及學童個案／活動、導師現場管理、假期活動、行政。
  • 優先經驗：社署課託、小學全方位社工；註冊社工（學位或以上）。
  • 工作現實：葵青區；週末及公眾假期或需輪班。
