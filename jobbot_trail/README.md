# HKPA 計劃主任即時模擬面試（jobbot_trail 優化試驗版）

本機、即時、完整一輪（起承轉合）的模擬面試平台，針對香港遊樂場協會賽馬會上葵涌青少年綜合服務（KIT）「計劃主任 ASWO／關愛基金在校課後託管」職位而設。

> 本資料夾（`jobbot_trail/`）係主專案嘅獨立試驗複本，用嚟驗證模型升級同評分邏輯優化，
> 唔會影響根目錄嗰個正式運作中嘅版本。詳細嘅優劣分析同優化內容見 [`OPTIMIZATION.md`](./OPTIMIZATION.md)。

## 你會得到什麼

- 模擬面試官（陳嘉敏姑娘）用香港粵語女聲發問，並按你的回答追問
- 你可用麥克風以粵語作答（可中英夾雜）；識字有誤可即場改字再送出
- 面試進行中不評分；結束後才出完整報告
- 報告含：逐題原文、優化完整答案、SS–D 評級（愈高成功機率愈高）、能力六角圖
- 每份報告自動存檔，可在首頁重看進度

## 電腦需求

已在本機驗證方向：Windows、NVIDIA GPU（例如 RTX 3080，VRAM 8GB 或以上）、約 16GB 記憶體。首次需下載：

1. [llama.cpp](https://github.com/ggml-org/llama.cpp) Windows Vulkan 版本（GitHub Release）
2. **Qwen3-8B-Instruct Q4_K_M**（[官方 GGUF](https://huggingface.co/Qwen/Qwen3-8B-GGUF)，約 4.7 GB）—— 檔案大小同上一代 Qwen2.5-7B 相若，但指令遵循同 JSON 結構化輸出更穩定，適合面試對答／評分呢類需要嚴格格式嘅任務。Qwen3 為混合思考模型，伺服器已強制關閉思考模式（`/no_think`）以確保低延遲同乾淨輸出，唔需要另外設定。

> ⚠️ 語音部分需要網絡：面試官語音使用 Microsoft Edge 雲端香港粵語女聲 `zh-HK-HiuMaanNeural`；語音輸入使用瀏覽器內建嘅香港粵語 `zh-HK` 辨識（Chrome／Edge 底層都係連去雲端辨識服務）。換言之，**只有面試對答同評分嘅語言模型推理係完全本機／離線；語音合成同語音輸入仍然需要連線**。如需完全離線，可自行改用本機 TTS／STT（例如 Piper、whisper.cpp）取代，但本專案暫未內建。

## 啟動

需要 [Node.js 18+](https://nodejs.org/)。在此資料夾執行：

```bash
npm install
npm start
```

瀏覽器開啟：**http://127.0.0.1:3001**（試驗版專用埠；原版仍係 3000）

首次進入首頁，按「下載本機引擎」。完成後即可開始完整模擬面試。一場約 12–15 分鐘（約 5–6 條主問題，加機動追問）。

亦可只預先下載引擎：

```bash
npm run setup
npm start
```

## 如何在不影響原版的情況下測試

詳見 [`TESTING.md`](./TESTING.md)。重點：

1. **只喺 `jobbot_trail/` 資料夾入面執行** `npm start`／`start.bat`，唔好改根目錄檔案。
2. 試驗版預設用 **網頁埠 3001、模型埠 8091**；原版仍係 3000／8090，兩邊唔會搶埠、亦唔會共用報告檔。
3. 語言模型檔案分開存放：試驗版下載 `Qwen3-8B` 到 `jobbot_trail/models/`，唔會覆蓋原版 `models/` 入面嘅 Qwen2.5。
4. llama.cpp 引擎可以**只讀沿用**原版已經下載好嘅 `vendor/`，唔使再下載一次，亦唔會改寫原版檔案。
5. **同一張 GPU 唔好同時載入兩個語言模型**（原版 Qwen2.5 + 試驗版 Qwen3）。測試試驗版前，請先關閉原版視窗（Ctrl+C）。

```bash
cd jobbot_trail
npm install
npm start
```

然後用 Chrome／Edge 開 http://127.0.0.1:3001 。原版如果之後要開返，去返 repo 根目錄執行 `npm start`，開 http://127.0.0.1:3000 。

## 評級（SS–D）

| 評級 | 分數 | 成功機率（練習用估算） |
| --- | --- | --- |
| SS | 9.3+ | 約 90% 以上 |
| S | 8.5+ | 約 75–90% |
| A | 7.5+ | 約 55–75% |
| B | 6.5+ | 約 35–55% |
| C | 5.0+ | 約 15–35% |
| D | 低於 5 | 約 15% 以下 |

六角圖維度：職位理解、個案與家庭工作、營運與導師管理、危機與保護兒童、協作與溝通、個人特質與抗壓。

分數來源會喺報告卡標示：「AI＋規則評分」代表本機語言模型已經對呢一題做語意評分（並用規則評分校正穩定性）；「離線規則評分」代表模型未就緒或者逾時，暫用純規則評分（例如答案過短、涉及答應「絕對保密」等）。
